This project is an attempt to construct and maintain a framework (lens) to look through at governance.
It seeks to capture enough universal factors that matter and can be recognized in governance.

It recognizes :
- universal factors
- historical factors
- inter dependencies

The universal character of the lens attempts to make universal comparison (times, countries, sectors)

The lens should suppress bias and reveal framing and should auto moderate.

The lens should work for artificial intelligent large language models.
